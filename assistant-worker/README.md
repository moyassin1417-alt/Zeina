# مساعد بيت زينة — إعداد السيرفر الوسيط (Cloudflare Worker)

الملف `worker.js` ده سيرفر بسيط مجاني شغله يحمي مفتاح Claude API ويوصّله بتطبيق
"بيت زينة". محتاج تعمله مرة واحدة بس.

## الخطوات

1. اعمل حساب مجاني على https://dash.cloudflare.com (لو مالكش واحد).
2. من القائمة الجانبية: **Workers & Pages** ← **Create** ← **Create Worker**.
3. اديله اسم زي `zeina-assistant` واضغط **Deploy** (هينشئ نسخة فاضية الأول).
4. ادخل على الـ Worker اللي عملته ← **Edit code**، امسح الكود الموجود، والصق
   محتوى ملف `worker.js` كامل، واضغط **Deploy** تاني.
5. ارجع لصفحة الـ Worker ← **Settings** ← **Variables and Secrets** ← **Add**،
   وضيف اتنين متغيرين من نوع **Secret**:
   - `ANTHROPIC_API_KEY` = مفتاحك من https://console.anthropic.com/settings/keys
     (لو معندكش مفتاح، تعمل حساب على console.anthropic.com وتنشئ مفتاح جديد من
     هناك — الاستخدام بيتحاسب حسب استهلاكك، شوف الأسعار على
     https://www.anthropic.com/pricing)
   - `APP_SHARED_SECRET` = أي كلمة سر تخترعها انت بنفسك (مثلاً `zeina-2026-xyz`)
6. احفظ، وهترجع صفحة الـ Worker تدّيك رابط شكله كده:
   `https://zeina-assistant.<اسمك>.workers.dev`
7. افتح تطبيق بيت زينة ← زرار المساعد 🤖 ← إعدادات ⚙️ ← الصق:
   - رابط المساعد = الرابط اللي فوق
   - الكود السري = نفس القيمة اللي حطيتها في `APP_SHARED_SECRET`

كده المساعد هيشتغل. أي تحديث لاحق على `worker.js` تعمله بنفس الخطوة ٤
(Edit code → الصق النسخة الجديدة → Deploy).

## ملاحظات

- المساعد حاليًا **يضيف بيانات جديدة بس** (مصروف، التزام، أصل، ذهب، هدف ادخار،
  مساهمة في هدف، مصروف ثابت) — مش بيعدّل ولا بيحذف ولا بيسحب حاجة، حماية من أي
  فهم غلط لرسالة.
- الكود السري (`APP_SHARED_SECRET`) مش حماية قوية 100%، بس بيمنع أي حد يلاقي
  رابط الـ Worker بالصدفة من استهلاك رصيدك.
- استخدام Claude API بيتحاسب بالاستخدام الفعلي (عدد الرسائل/الكلمات) — مش
  مجاني زي باقي التطبيق.
